# VCE Work & Money Flow Tracker — User Guide

Welcome to the **Work & Money Flow Tracker**! This system is your daily work ledger + money ledger designed specifically for freelancers, consultants, and independent working professionals.

---

## 1. The Core Philosophy
The core workflow of this tool is:
$$\text{Person} \longrightarrow \text{Work} \longrightarrow \text{Agreed Amount} \longrightarrow \text{Payments} \longrightarrow \text{Pending Udhar} \longrightarrow \text{Expenses} \longrightarrow \text{Profit}$$

---

## 2. Keyboard Shortcuts for Super-Fast Entry
From anywhere in the application (unless typing in a text field):
- Press `W` : Open **+ Add Work** dialog.
- Press `P` : Open **+ Add Payment (Income)** dialog.
- Press `E` : Open **+ Add Expense** dialog.
- Press `C` : Open **+ Add Person / Client** dialog.
- Press `Esc` : Close any active modal.

---

## 3. Daily Workflow Checklist
1. **Morning**:
   - Open Dashboard (`/pages/dashboard.html`).
   - Check **Today's Work & Upcoming Deadlines**.
2. **During the Day**:
   - Record newly received work assignments using `+ Work`.
   - As payments arrive, click `+ Payment` or press `P`. Choose whether the money arrived via **Online**, **Cash**, or **Udhar**.
   - Note down expenses (travel, software licenses, materials) using `+ Expense` or press `E`.
3. **Evening Review**:
   - Verify **Today's Revenue**, **Today's Expenses**, and **Net Profit**.
   - Review **Pending / Udhar** to track which clients need follow-up.

---

## 4. Understanding Financial Figures
- **Revenue Received**: Total money actually collected via cash or online channels. Udhar is tracked separately as a pending receivable until realized.
- **Cash-Flow Profit**: `Revenue Received - Expenses`.
- **Expected Profit**: Total value of agreed work minus incurred expenses.
- **Pending Amount**: `Agreed Amount - Sum of Linked Received Payments`. You never need to calculate this manually!

---

## 5. 1-Click Exporting
Navigate to **Reports & Exports** (`/pages/reports.html`) to view statements and download them instantly in:
- **CSV** (for spreadsheets and custom accounting scripts)
- **Excel (.xlsx)** (styled with corporate header formatting and column autosizing)
- **PDF** (ready for printing and client records)
